# Week 4 Audit Records

These files record the reproducibility review of the
committed repository snapshot identified in source_commit.txt.

| File | Purpose |
|---|---|
| source_commit.txt | Audited Git commit |
| verification_report.txt | Automated stored-data checks |
| week2_source_review.txt | Week 2 logs and analyzer inspection |
| week2_regeneration.log | Week 2 analysis execution output |
| figure_regeneration.log | Isolated figure-generation attempts |
| figure_comparison.txt | Original versus regenerated PNG comparison |
| memory_regeneration_commands.txt | Memory analyzer invocation review |
| provenance_review.txt | Git tracking and historical source review |
| environment_review.txt | Historical experiment environment records |

Use the actual recorded outcomes to determine which checks
passed and which require further review.

Warnings are evidence limitations, not proof of failed experiments.
Failures must not be relabeled as successful checks.

No historical raw experiment files were intentionally overwritten
during this audit.

See [Reproducibility and Data Integrity](../../docs/REPRODUCIBILITY.md).
