===== MEMORY ANALYZER OPTIONS =====
usage: analyze_memory_claim2.py [-h] --log LOG --out OUT [--env ENV]
                                [--compare LOG;LABEL;ENV]
                                [--paper-mem PAPER_MEM]

Build the Claim 2 (memory overhead) tables and figures from a b1-b4 run
matrix.

options:
  -h, --help            show this help message and exit
  --log LOG             runs.log of the session being reported
  --out OUT             output directory (created if missing)
  --env ENV             environment.txt of the same session (embedded in
                        summary.md)
  --compare LOG;LABEL;ENV
                        additional session for figure C: path;short label;one-
                        line environment
  --paper-mem PAPER_MEM
                        paper Table 1 average (3.37x)

147-## 7. Data-quality notes
148-
149-- n = 3 per bar is the rubric minimum, not a comfortable sample. The per-run
150-  VmHWM values are stable to a few kB except b1 (+/- 1.7 MB base, +/- 0.7 MB
151-  ASan), so the ratios are dominated by the allocation pattern, not by noise.
152-- Two wall-time outliers exist in the primary session and one in the second
153-  (b2 ASan run 3 at 3256 ms, b4 ASan run 3 at 2485 ms against ~1.0 s / ~0.4 s
154-  for their siblings). They are WSL2 host stalls: they are kept in the data and
